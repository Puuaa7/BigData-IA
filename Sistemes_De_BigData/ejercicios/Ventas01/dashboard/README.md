# Dashboard Ventas01

Interfaz React y Next.js en JavaScript (`app/page.jsx` y `app/layout.jsx`).

Desde la carpeta superior Ventas01 ejecuta `node scripts/procesar.mjs`.
Después, desde esta carpeta ejecuta `npm run dev` y abre la URL local indicada.
Pulsa «Actualizar datos» tras regenerar los JSON.

Consulta `../README.md` para reglas, resultados, verificaciones y limitaciones.
